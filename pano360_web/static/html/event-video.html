영상 만들기 — 노드 파일로
화질 올린 이 360 + 위에서 칠한 범위 + 위 프롬프트를 노드 파일 (video_nodes/retest.json, config video_template)에 값만 넣어 그대로 실행해요. 노드가 사각 마스크(SolidMask·MaskComposite)면 칠한 범위를 감싸는 좌표를, 마스크 그림(LoadImage)이면 그림을 넣어요. 값 넣은 노드 파일도 받을 수 있어요(ComfyUI 에서 그대로 열림). 보통 5~15분.
같은 범위에서 사건 없이 평소 흐름만 (예: 계곡물이 계속 흐름). 있으면 Quest 에서 사진이 멈춰 있지 않고 평소 움직임 → 사건 → 평소 로 끊김 없이 반복돼요.
