5영상화 · 움직일 곳과 프롬프트 

    
화면 전체가 아니라 일부만 움직여요. LLM 이 결과 360 과 생성 프롬프트를 보고 물·구름·나뭇잎처럼
      움직이면 살아나는 곳을 고르고, 영역마다 영상 모델(LTX-2.3 Cinemagraph)용 프롬프트를 만들어요. 영역 밖은 8K 정지 이미지 그대로예요.

        360 영상 만들기
        
① 영역 영상 만들기 — 영역마다 움직일 것 모양 마스크(SAM 3)와 짧은 영상(LTX-2.3 + Cinemagraph)을 클라우드에서 만들어요.

          ② 360 합성 — 마스크 안만 영상으로 바꾸고 나머지는 원본 정지 화면 그대로 360 에 합쳐 MP4 로 저장해요(이 PC 에서, 끝과 처음은 이어지게). 영역 영상을 다시 만들지 않고 몇 번이든 다시 합성할 수 있어요.

        

          

          

          

          

          

        

        

        

          
          

            
            

            

          

        

      

    

  


  

    
6사건 영상 · 한 번 일어나는 연출 

    
잔잔하게 시작 → 물이 넘쳐 화면을 덮음 → 다시 잔잔하게 끝. 넓은 사건 화면(16:9)을 잘라 영상 모델(Wan 2.2)로 만들고,
      결과 영상을 올리면 원본에서 달라진 곳만 360 위에 섞어요. 나머지는 8K 원본 그대로예요.
