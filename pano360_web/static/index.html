5움직일 곳(마스크) · 영상 프롬프트 

    
LLM 이 결과 360 과 생성 프롬프트를 보고 물·구름·나뭇잎처럼 움직이면 살아나는 곳을 고르고,
      영역(마스크)과 영상 모델(LTX 등)용 프롬프트를 만들어요. 영상 생성은 ComfyUI 에서 해요.

6사건 연출 · 프롬프트와 움직일 범위 

    
잔잔하게 시작 → 물이 넘쳐 화면을 덮음 → 다시 잔잔하게 끝. LLM 이 연출과 영상 프롬프트를 만들고,
      360 위에 움직일 범위를 칠해 마스크 PNG 로 받아요. 영상 생성은 ComfyUI(LTX) 에서 해요.

        움직일 범위 (마스크)
        
360 그림 위에 움직일 곳을 칠하고 '범위 저장' → 마스크 PNG(2048×1024, 흰색 = 움직일 곳)를 받아 ComfyUI 에 쓰세요. 좌우 끝은 이어져요.

        

          
          
        

        

          

          

          

          

          

          

        

      


      

        360 전체 영상 프롬프트 — LTX-2.3 + 360 LoRA 에 360 이미지를 그대로 넣을 때 ('사건 만들기'를 하면 그 내용이 들어가요)
        
        
        
        
        

          

          

          

        

      


      

        영상 만들기 — 노드 파일로
        
화질 올린 이 360 + 위에서 칠한 범위 + 위 프롬프트를 노드 파일
          (video_nodes/retest.json, config video_template)에 값만 넣어 그대로 실행해요.
          노드가 사각 마스크(SolidMask·MaskComposite)면 칠한 범위를 감싸는 좌표를, 마스크 그림(LoadImage)이면 그림을 넣어요.
          값 넣은 노드 파일도 받을 수 있어요(ComfyUI 에서 그대로 열림). 보통 5~15분.
